# TypeScript-Startprojekt

Mit diesem Projekt kann in TypeScript durchgestartet werden. Öffne die Datei `src/game.ts` und starte die Vorschau im Terminal mit `npm run dev`.

Wenn `npm run dev` läuft, wird TypeScript beim Speichern automatisch im Hintergrund nach JavaScript kompiliert und die Vorschau anschließend neu geladen. Für die Arbeit im Kurs muss die Konfiguration nicht verändert werden.

## Installierte Bibliotheken

- p5.js: Bibliothek zum Zeichnen und Erstellen interaktiver Grafiken im Browser.
- Matter.js: Physik-Engine zur Simulation von Körpern, Kollisionen und Kräften.
